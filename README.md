# M ARCHIVE // Streetwear & Apparel Experience

Experiencia web moderna e inmersiva con renderizado 3D en tiempo real (Three.js / React Three Fiber), estética monocromática urbana y conversión directa a WhatsApp.

## 🚀 Tecnologías
- **Vite + React (TypeScript)**
- **Three.js + @react-three/fiber + @react-three/drei** (Camiseta 3D interactiva, spotlight y proyecciones Decal)
- **Tailwind CSS** (Tipografías personalizadas: Clash Display & DM Mono Italic)
- **Framer Motion** (Animaciones fluidas estilo Cuberto y reveal de textos)
- **Simplex Noise** (Ondas fluidas procedurales de fondo)
- **Lucide React** (Iconografía minimalista)

## 📦 Estructura del Proyecto
- `/src/components/3d`: Escena 3D, modelo de la camiseta, luces de estudio y gestor de decals.
- `/src/components/ui`: Secciones Hero, Marquee, Colecciones, Slider de diseños y Footer.
- `/src/components/wholesale`: Módulo de venta mayorista con cotizador directo a WhatsApp.
- `/src/data`: Catálogo de productos, diseños y tiers mayoristas.
- `/public/prints`: Gráficas y estampas optimizadas para el modelo 3D.
- `/docs/REFERENCES.md`: Registro completo de todas las webs de referencia, ejemplos 3D y tipografías.
- `/docs/FUTURE_UPDATES.md`: Hoja de ruta para futuras mejoras (fuente Grenze, cloth physics y editor de estampas).


## 🛠️ Comandos
```bash
npm run dev   # Iniciar servidor local
npm run build # Compilar para producción
npm run preview # Previsualizar build
```
